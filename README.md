# Практическая работа по дисциплине «Введение в HTML»

Проект содержит четыре учебные HTML-страницы, демонстрирующие базовые возможности HTML:

1. Базовая структура HTML-документа и форматирование текста.
2. Персональная веб-страница с заголовками, списками, таблицей, ссылками и мультимедиа.
3. Форма обратной связи с базовой валидацией.
4. Страница с семантической разметкой HTML5.

## Структура проекта

- `index.html` — стартовая страница со ссылками на все задания.
- `task1.html` — Задача 1. Базовая HTML-страница.
- `task2.html` — Задача 2. Персональная веб-страница.
- `task3.html` — Задача 3. Форма обратной связи.
- `task4.html` — Задача 4. Семантическая разметка.
- `assets/img/` — изображения.
- `assets/media/` — видеофайл.

## Запуск

Проект не требует установки сервера.

### Вариант 1. Открытие напрямую

1. Клонировать или скачать репозиторий.
2. Открыть файл `index.html` в браузере.
3. Переходить по ссылкам на страницы заданий.
